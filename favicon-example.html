Favicon Configuration Example

This HTML file demonstrates how to configure favicons using traditional HTML meta tags.

Current Favicon Setup:

  • Main favicon: /favicon1.png
  • Apple Touch Icon: /favicon1.png
  • Theme color: #8B5CF6

Traditional HTML Favicon Tags:

<link rel="icon" href="/favicon.ico" type="image/x-icon">
<link rel="icon" href="/favicon.png" type="image/png" sizes="32x32">
<link rel="apple-touch-icon" href="/apple-touch-icon.png">

Next.js App Directory (Current Setup):

export const metadata = {
  icons: {

}
